# Contributors / 贡献者名单

Thank you to all contributors who have helped improve this project!

感谢所有为项目改进提供帮助的贡献者！

## English Version



* **meowyih**: Discovered the incompatibility bug of the add-on with Blender 5.0 (caused by Blender removing outdated APIs), promoting version compatibility optimization.

* **Bouscout**: Proposed a new feature suggestion for bone renaming, recommending the use of Blender's standard suffix format for task bone names to improve naming consistency.

* **spinalcord**: Proposed the "Root Bone Rotation Support" feature suggestion and provided core code implementation, optimizing root bone rotation functionality.

## 中文版本



* **meowyih**：发现插件在 Blender 5.0 版本中的不兼容问题（因 Blender 移除过时 API 导致），推动了版本兼容性优化。
